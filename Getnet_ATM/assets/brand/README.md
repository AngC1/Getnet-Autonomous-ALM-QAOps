# Logos de referencia

`logo-ayesa-boletin.webp` y `logo-vector_ayesa.webp` son **sustitutos provisionales**
generados con Pillow (simbolo de 4 petalos azul #1a1adb + wordmark "ayesa").

- `logo-ayesa-boletin.webp`: logo CORRECTO (con "digital").
- `logo-vector_ayesa.webp`: logo INCORRECTO (sin "digital").

Reemplazalos por los archivos reales con **el mismo nombre** (WebP, < 1 MB).
Si los cambias, borra las copias en `brand/reference/` del bucket S3 para que se vuelvan a subir.
